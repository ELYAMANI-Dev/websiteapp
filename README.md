# OTMATRANS Business Manager

OTMATRANS is a local-first operations management app for tracking quality control, equipment checkout, shipment logs, and compliance reporting.

## Features

- Create and manage daily operational records
- Track ownership, due dates, progress, and notes
- Review equipment, shipment, quality, and compliance status
- Store records locally on the Android device
- No account or cloud synchronization required
